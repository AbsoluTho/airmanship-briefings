# Airmanship Briefings

A flight preparation aid built on Airbus FCTM concepts. Import the Mission Plus OFP and NOTAM PDFs, work through the Dispatch Briefing in form order, check tankering and underload, and run the cabin crew, departure and jumpseat briefings. Up to four sectors.

- Works in any modern browser and installs as an app on iPhone, iPad and Android.
- Works offline after the first visit.
- Everything you type, and every PDF you import, stays on your device. Nothing is uploaded.

## Install on a phone or tablet

- **iPhone / iPad:** open the page in Safari, tap Share, then Add to Home Screen.
- **Android:** open the page in Chrome, tap the menu, then Install app (or Add to Home screen).

## Important

This is an unofficial preparation aid. It does not replace the FCOM, FCTM, the operator's OM-A or any company procedure, and it is not affiliated with any airline. Verify every figure against approved sources.
